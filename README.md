## Problem Statement

A fulfillment robot receives a stream of n parcels a[1 ... n] and loads them into a rack with n slots arranged left to right. It follows an alternating placement policy:

- it puts a_1 into the leftmost empty slot;
- it puts a_2 into the rightmost empty slot;
- then, as far left as possible among remaining slots, it places a_3;
- then, as far right as possible among remaining slots, it places a_4;
- the robot continues in this alternating manner until all parcels are placed.

After loading completes, reading the rack from left to right yields the sequence b[1 ... n]. You are given b and must reconstruct the original arrival order a.

## Input

```
The first line contains a single positive integer t (1 ≤ t ≤ 300) — the number of test cases. Then t test cases follow.

The first line of each test case contains an integer n (1 ≤ n ≤ 300) — the length of the rack.

The next line contains n integers b_1, b_2,…, b_n (1 ≤ b_i ≤ 10^9) — the contents of the rack from left to right.
```

## Output

```
Output t answers to the test cases. For each test case, print the sequence a corresponding to the arrival order that would produce the observed rack layout b under the described alternating placement.
```
